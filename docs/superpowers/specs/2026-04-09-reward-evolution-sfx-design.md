# 奖励卡片旋转弹出与宠物升级动画音效设计

## 背景

当前项目已经有独立的音效预览页与战斗音效合成逻辑，但“奖励卡片旋转弹出”和“宠物升级动画”还缺少可快速比对的专属音效方案。目标是先做一个独立 HTML 试听页，用纯 Web Audio 合成多套候选方案，快速确认方向，再把选中的参数迁移进正式游戏逻辑。

## 目标

1. 为“奖励卡片旋转弹出”设计 3 套偏“稀有掉落感”的音效。
2. 为“宠物升级动画”设计 3 套偏“神圣进化感”的音效。
3. 提供一个独立 HTML 试听页，支持逐个播放、顺序连播、停止全部、主音量调节。
4. 试听页视觉风格与仓库现有预览页保持一致，偏明亮、高级、适合儿童游戏。

## 非目标

1. 这一轮不直接接入 React 正式业务组件。
2. 不引入外部音频素材或第三方音源库。
3. 不追求真实乐器质感，优先保证情绪表达、可调参与快速迭代。

## 用户已确认的创意方向

### 奖励卡片旋转弹出

- 核心情绪：稀有掉落感
- 关键词：闪耀、旋转、稀有、高价值、解锁

### 宠物升级动画

- 核心情绪：神圣进化感
- 关键词：升腾、圣光、蜕变、完成仪式感

## 方案结构

### 奖励卡片旋转弹出

提供 3 个方案，统一保持“稀有掉落感”，但拉开冲击层级：

1. `轻奢`
   - 听感：轻吸附上升 + 细腻星点 + 柔和亮闪尾音
   - 使用场景：通用高品质奖励，频繁触发也不刺耳
2. `华丽`
   - 听感：更明显的旋升感 + 水晶亮面感 + 高级解锁完成音
   - 使用场景：推荐主方案，兼顾惊喜与耐听
3. `爆闪`
   - 听感：短促预吸附 + 明亮爆开 + 强尾闪
   - 使用场景：更接近 SSR 或超稀有奖励，不建议泛用

### 宠物升级动画

提供 3 个方案，统一保持“神圣进化感”，但拉开庄严程度：

1. `纯净`
   - 听感：能量上升更轻，明亮、纯净、偏治愈
   - 使用场景：低年级或更温柔的进化氛围
2. `神圣`
   - 听感：圣光聚集 + 光柱抬升 + 温暖绽放
   - 使用场景：推荐主方案，最贴合当前目标
3. `庄严`
   - 听感：更长的蓄势 + 更稳的完成钟感 + 更正式的仪式气质
   - 使用场景：关键进化、隐藏形态或里程碑升级

## 推荐组合

- 奖励卡片：`华丽`
- 宠物升级：`神圣`

推荐原因：二者都具备高级感与明确的成长反馈，但情绪边界足够清楚，不会出现“两个场景听起来像同一个事件”的问题。

## 技术设计

### 页面形态

新增独立试听页，路径暂定为 `public/reward-evolution-sfx-lab.html`。

页面包含：

1. 顶部说明区
   - 当前设计目标
   - 推荐组合
   - 使用说明
2. 全局控制区
   - `解锁音频`
   - `顺序连播推荐`
   - `停止全部`
   - 主音量滑杆
3. 奖励卡片音效区
   - 3 个方案卡片
   - 每个方案有关键词、听感描述、播放按钮
4. 宠物升级音效区
   - 3 个方案卡片
   - 每个方案有关键词、听感描述、播放按钮
5. 状态提示区
   - 当前播放方案
   - 当前推荐组合
   - 移植建议

### 声音合成策略

使用浏览器 `AudioContext` + `OscillatorNode` + `GainNode` + `BiquadFilterNode` + 噪声缓冲合成，不依赖外部素材。

#### 奖励卡片音效设计原则

音色层按以下结构组合：

1. `吸附前摇`
   - 很短的 upward glide，制造“卡片被吸上来”的感觉
2. `旋转闪耀主体`
   - 高频 bell / triangle / sine 叠层，做出亮晶晶的旋转感
3. `稀有完成尾音`
   - 简短高光尾部，提示“获得成功”

参数差异主要体现在：

- 起始频率和滑音速度
- sparkle 密度
- 尾音长度与亮度
- 是否增加 burst 感

#### 宠物升级音效设计原则

音色层按以下结构组合：

1. `能量聚集`
   - 更慢的 upward pad-like 上升
2. `圣光抬升`
   - 明亮泛音逐渐打开，形成升腾感
3. `进化绽放`
   - 带一点钟感或 choir-like 感觉的完成音

参数差异主要体现在：

- 蓄势时间
- 泛音宽度
- 完成音的钟感与庄严程度
- 低频支撑是否明显

### 视觉联动

试听页中的每个播放按钮触发时，同步在卡片中播放一个轻量视觉 cue：

- 奖励卡片区：闪环、旋转辉点、瞬时高光
- 宠物升级区：光柱、扩散环、粒子上升

该联动只用于帮助判断音画是否匹配，不追求完全复刻正式动画。

## 交互规则

1. 首次进入页面，用户需要点击 `解锁音频` 以激活音频上下文。
2. 任何一次新播放开始前，都先停止前一次试听，避免叠音。
3. 点击 `顺序连播推荐` 时，按“奖励卡片华丽 -> 宠物升级神圣”的顺序自动播放。
4. 主音量滑杆实时生效。
5. 页面需要兼容桌面与移动端触控操作。

## 验收标准

1. 页面能在本地开发环境正常打开。
2. 6 个方案都能单独播放，无报错。
3. 推荐组合连播可正常工作。
4. 停止全部能及时中断当前声音。
5. 在移动端宽度下布局不破坏，按钮可点击。
6. 不依赖外部音频文件，离线可试听。

## 后续迁移建议

若本轮确认方案方向正确，下一步应将推荐组合的参数整理为单独函数，迁移到正式前端代码中，供奖励卡片弹出与宠物升级动画触发时调用。
