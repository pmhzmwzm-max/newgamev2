Growth Retention PRD

前50关成长上瘾机制工作台

这份 HTML PRD 只定义三个允许改动的触点：地图页、完成页、宠物图鉴。主目标不是增加新系统，而是把现有资源重新编排成一条更上瘾的成长链： 让孩子持续感到“我又拿到了新东西”，同时持续感到“我离下一次宠物进化不远”。游戏页、答题页、战斗页以及地图路径样式全部明确锁死，不纳入本轮变更范围。

1. 核心目标

主命题：前50关必须持续制造两种感受：我又拿到了新东西 与 我离下一次进化不远。

主驱动：宠物形态成长。

辅助驱动：攻击特效颜色、宝石颜色、背景图切换。

2. 改动边界

允许调整

地图页：直接基于当前实际 MapScreen 效果，只优化单个关卡 icon / 角标 / 提示徽记。

完成页：保留当前实际结果页的统计卡与按钮，只把额外奖励放进原“获得新宠物”卡片样式里。

宠物图鉴：重做成长链展示、当前进度与终点感。

明确禁止

不可调整游戏页 / 答题页 / 战斗页。

不可调整地图路径位置、走向、连线样式，以及除关卡 icon 外的地图主体效果。

不可新增强化态、装备栏、章节系统、新资源种类。

现有实现边界对应：src/components/MapScreen.tsx、src/components/ResultScreen.tsx、src/components/PokedexScreen.tsx。src/components/QuizScreen.tsx 不纳入本轮。

3. 资源池约束

宠物形态

7种，含蛋与最终形态。所有重大高潮都服务于这条主链。

背景

只换背景图，不改地图路径和场景结构。

宝石颜色

只换颜色，承担阶段升级与“越来越高级”的感受。

攻击特效颜色

只换颜色，承担更高频的小奖励，补齐中段空窗。

4. 前50关三段节奏

1-15关

目标：快速上钩、快速确认“会一直变化”。

规则：无奖励关最多连续1关；宠物变化频率高；奖励密度高。

16-35关

目标：建立稳定追更感。

规则：无奖励关最多连续2关；继续推进宠物成长；用特效 / 宝石 / 背景填中段空隙。

36-50关

目标：冲刺最终形态。

规则：无奖励关最多连续3关；奖励间隔可拉长但要强提示；50关必须给最终形态。

5. 宠物成长主链

初始

形态0 · 蛋

进入地图时的起点，不需要任何战斗页改造即可理解成长起源。

第1关

形态1

新手脚本孵化，第一关必须立刻兑现，让玩家相信游戏会持续变化。

第3关

形态2

前期快速第二次反馈，巩固“成长很近”的预期。

第8关

形态3

承接前段高频变化的第一个小高潮。

第15关

形态4

前段收束点，明确告诉玩家成长链还会继续。

第25关

形态5

中段托举点，用于避免“打到中间没新鲜感”。

第38关

形态6

后段冲刺起点，正式进入终局预热。

第50关

形态7 · 最终形态

本版终点爆点，完成页与图鉴都必须把它当成阶段完成时刻。

累计规则：经验始终累计，不清零。每次进化后，分子保留当前累计经验，分母切换为下一次进化所需总经验。

体验价值：不让玩家产生“我又重新开始”的挫败感，而是持续确认“我已经积累很多”“我离下一次变化越来越近”。

7. 完成页主提示判断逻辑

new_reward

本关已获得新奖励。展示在原“获得新宠物”旋转礼花卡中，结果页底板不改。

next_reward

本关无奖励，且下一资源距离 ≤ 2 关。仍使用同一张礼花卡，只是内容换成“n关后获得xxx（神秘黑盒奖励）”。

next_evolution

本关无奖励，下一资源不够近，但下一进化距离 ≤ 20 经验。礼花卡里的成长模块直接展示下一形态剪影与进度推进。

finale

第50关仍使用同一张礼花卡形态，只把内容推到终局版本，不再额外设计另一套卡壳结构。

统一卡片规则：额外奖励与提示只允许使用原“获得新宠物”卡片样式（旋转弹出 + 礼花特效）。当前版本不再拆多套奖励卡壳。

8. 预热关强化文案

预热节点

第7、14、24、37、49关是核心预热关，哪怕本关没新奖励，也要强化“再来一关，宠物就会进化”。

允许文案

“再来一关，宠物就会进化” / “下一关将解锁新形态”。这属于文案强化，不算新增资源。

9. 前50关资源锚点表

关卡 宝石 本关经验 累计经验 经验条显示 距下次进化 本关新奖励 下一资源目标 主提示焦点

10. 可改页面定义

地图页

直接读取当前实际地图页效果，只优化单关图标、徽记、角标与资源提示。路径样式、路径位置、背景与整体结构一律不改。

完成页

保留当前实际结果页中的【闯关时间】【正确率】【最高连击】【下一关】【返回路线】。所有额外奖励与提示统一由原“获得新宠物”卡片承载。

宠物图鉴

只围绕7种形态成长链做重构，承担长期成长确认，不承担即时奖励结算。

游戏页

明确不进入本版。任何试玩、战斗、答题反馈、路径战斗逻辑都不在此 PRD 的改造范围内。
